# Continuidade do Mythreon Online

- A entrada do conhecimento é `00 - Comece aqui.md`, seguida da nota pertinente em `docs/conhecimento/00 - Fonte de conhecimento.md`.
- O cofre Obsidian é a raiz do projeto. `docs/conhecimento/` contém as notas autorais, fonte de regras, decisões e procedimentos; `CEREBRO_MYTHREON.md` contém contexto e continuidade histórica.
- Use leitura seletiva. Consulte o código para confirmar comportamento e notas antigas antes de implementar novamente alguma função.
- Após alterações relevantes, atualize a nota original do sistema, registre evidências e limites, acrescente continuidade ao Cérebro e execute `npm run brain:sync`.
- `Mythreon Obsidian/` e `.mythreon-brain/` são saídas automáticas; não escreva decisões originais ali. Não apague arquivos autorais para limpar o grafo.
- Não indexe nem leia binários de release para documentar o jogo. Não registre segredos. Trate `experimental/` como referência não revisada.
- Preserve saves e alterações existentes. Não faça push/deploy/publicação sem pedido do usuário. Não declare verificações que não foram executadas.
