# Skins humanas de Mythreon

O catálogo em src/data/cosmetics.ts define os caminhos. Para o Manto da Nebulosa, salve aqui:

- SKIN_MANTO_NEBULOSA.png — personagem humano completo com a roupa, e não somente um ícone de capa.

Use corpo inteiro, pose de combate neutra em três quartos, contorno nítido e proporção semelhante à sprite humana atual. Fundo transparente. GIF e GIFF também são reconhecidos pelo carregador; PNG é a preferência inicial das sprites da pasta players.

A skin mensal do Primeiro Canto já usa public/assets/items/SKIN_PREMIUM_MES_01.png. Não precisa copiá-la para esta pasta.

Se uma skin faltar ou falhar, o jogo usa o humano de base com as cores salvas. Recarregue a página depois de adicionar uma arte que antes estava ausente.
